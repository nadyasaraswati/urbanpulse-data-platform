# UrbanPulse — Traffic & Weather Analytics (Streamlit)

Jalankan:

    pip install -r requirements.txt
    streamlit run app.py

Data: taruh 4 file CSV di folder `data/` (di sebelah `app.py`) atau unggah lewat sidebar:
`gold_dim_location.csv`, `gold_weather_traffic_hourly.csv`, `silver_traffic_30min.csv`, `silver_weather_hourly.csv`.

Deploy ke Streamlit Community Cloud: commit `app.py`, `requirements.txt`, dan folder `data/` ke repo GitHub.
